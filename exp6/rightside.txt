AIM:
Write a Java program to illustrate the concept of access protection using packages.

ALGORITHM:
1. Start
2. Create a package pkg1 containing ClassA with public, protected, default and private members
3. Create ClassB in pkg1 which accesses the public, protected and default members of ClassA
4. Create a package pkg2 containing ClassC which accesses only the public members of ClassA
5. Import pkg1 and pkg2 into the main class
6. Create objects of ClassA, ClassB and ClassC in the main method
7. Access their respective members and display the result
8. Stop
