AIM:
Write a Java program to implement access protection in packages.

Access Specifier Rules Summary

Access Specifier | Same Class | Same Package (Subclass & Non-Subclass) | Different Package (Subclass) | Different Package (Non-Subclass)
---|---|---|---|---
private | Yes | No | No | No
default (no keyword) | Yes | Yes | No | No
protected | Yes | Yes | Yes (via inheritance) | No
public | Yes | Yes | Yes | Yes

Algorithm
1. Create a package named pkg1.
2. Inside pkg1, create a class BaseClass with four variables having different access modifiers:
   - private int pri_n
   - int def_n (default / package-private)
   - protected int pro_n
   - public int pub_n
3. Inside pkg1, create a second class SamePackageClass to test access:
   - Instantiate BaseClass.
   - Access def_n, pro_n, and pub_n (note that pri_n is inaccessible).
4. Create a second package named pkg2.
5. Inside pkg2, import pkg1.BaseClass and create a subclass SubClass:
   - Inherit from BaseClass.
   - Access pro_n and pub_n directly (note that pri_n and def_n are inaccessible).
6. Inside pkg2, create a non-subclass OtherPackageClass:
   - Instantiate BaseClass.
   - Access only pub_n (note that pri_n, def_n, and pro_n are inaccessible).
7. Create a driver/main class to instantiate and call the display methods of all classes to demonstrate visibility.
8. Stop
