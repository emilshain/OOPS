AIM:
To find frequency of a given character in a string.

ALGORITHM:
1. Start
2. Read the input string
3. Read the character whose frequency is to be found
4. Initialize a variable count = 0
5. Traverse the string from the first character to the last:
    5.1. If the current character matches the given character:
        5.1.1. Increment count
6. Display the value of count
7. Stop
