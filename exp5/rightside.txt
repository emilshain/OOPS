AIM:
Write a Java program to create an abstract class Shape with subclasses Rectangle, Triangle and Hexagon. Calculate the area of each shape.

ALGORITHM:
Step 1: Start
Step 2: Create an abstract class Shape with a method area()
Step 3: Create a class Rectangle that extends Shape:
    3.1: Define a method collectInput() to get length and breadth
    3.2: Define a method calculateArea() to calculate length * breadth
Step 4: Create a class Triangle that extends Shape:
    4.1: Define a method collectInput() to get base and height
    4.2: Define a method calculateArea() to calculate 0.5 * base * height
Step 5: Create a class Hexagon that extends Shape:
    5.1: Define a method collectInput() to get side
    5.2: Define a method calculateArea() to calculate the area of the hexagon
Step 6: Define a class ShowResult to display the result
Step 7: In main, create objects for Rectangle, Triangle and Hexagon, call collectInput(), calculateArea() and showResult()
Step 8: Stop
