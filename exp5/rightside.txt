AIM:
Create a abstract class name Shape that contains an empty method named noOfSides(). Provide three classes named Rectangle, Triangle and Hexagon such that each one of the classes extends the Class Shape. Each one of the classes contains only the methods noOfSides() that shows the no. of Sides in a given geometrical structure.

ALGORITHM:
1. Start
2. Create an abstract class Shape with an abstract method noOfSides()
3. Create a class Rectangle that extends Shape and defines noOfSides() to display 4
4. Create a class Triangle that extends Shape and defines noOfSides() to display 3
5. Create a class Hexagon that extends Shape and defines noOfSides() to display 6
6. Create a Shape reference for Rectangle in the main method and call noOfSides()
7. Create a Shape reference for Triangle in the main method and call noOfSides()
8. Create a Shape reference for Hexagon in the main method and call noOfSides()
9. Stop
