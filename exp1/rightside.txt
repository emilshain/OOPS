AIM:
To check whether a given string is Palindrome or not using Java.

ALGORITHM:
1. Start
2. Input a string
3. Initialize an empty string: reversed = ""
4. Traverse the input string from the last character to the first:
    4.1. Append each character to reversed
5. If both strings (original and reversed) are equal:
    5.1. Display "String is Palindrome"
6. Otherwise:
    6.1. Display "String is not Palindrome"
7. Stop
